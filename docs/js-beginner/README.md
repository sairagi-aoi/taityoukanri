# JavaScript 入門 ― 「体調記録」アプリで学ぶ

このディレクトリは、同じリポジトリにある **体調記録アプリ** (`index.html` / `style.css` / `app.js` / `xlsx.js`) を
教材にした、JavaScript 初学者向けの学習資料です。

## この教材の特徴

- **架空のサンプルコードではなく、実際に動いているアプリのコードを読みます。**
  文法の説明のためだけに作られたコードではないので、「その文法が現場でどう使われるか」がそのまま分かります。
- **外部ライブラリを一切使っていません。** React も jQuery も出てきません。
  ブラウザが最初から持っている機能 (DOM API・localStorage・Blob など) だけで、
  フォーム入力・保存・一覧表示・グラフ描画・Excel 書き出しまで実装されています。
- **環境構築が不要です。** `index.html` をダブルクリックしてブラウザで開けば、すぐ動きます。

## 対象読者

- 他の言語を少し触ったことがある、あるいはプログラミング自体が初めての人
- HTML と CSS はなんとなく読める人 (完全に初めてでも第1章で最低限を補います)
- 「文法は本で読んだけれど、実際のアプリがどう組み立てられているか分からない」人

## 学習の進め方

1. まず **`index.html` をブラウザで開いて、アプリを実際に触ってください。** 数日分の記録を入力し、
   編集・削除・Excel書き出しまで一通り試します。「何を作っているのか」を体で分かってから読むと、理解が段違いです。
2. 第1章から順に読みます。各章には該当する**実際のコードの引用と行番号の目安**が載っています。
   必ずエディタで `app.js` を開き、**引用元の箇所を自分の目で探しながら**読んでください。
3. 各章末の「やってみよう」を必ず手を動かして解きます。読むだけでは書けるようになりません。
4. 全章を終えたら `13-演習問題.md` に挑戦します。解答例は `14-演習の解答例.md` にあります。

## 学習の目安時間

1章あたり 30〜60 分、演習を含めて全体で 12〜16 時間程度を想定しています。
1日1章ずつ、2週間かけて進めるくらいがちょうどよいペースです。

## 注意

教材中のコードは、読みやすさのために実際のコードから一部を省略・整形している箇所があります。
**最終的に正しいのは常にリポジトリの実際のファイル**です。必ず本物を開いて確認してください。
