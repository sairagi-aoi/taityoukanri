# 付録 用語集とチートシート

---

## 用語集

### あ行

**アロー関数 (arrow function)**
`(a, b) => a + b` という書き方の関数。短く書け、コールバックによく使われる。→ 第4章

**イベント (event)**
クリックや入力など、ブラウザ上で起きる出来事。→ 第7章

**イベント委譲 (event delegation)**
子要素それぞれにリスナーを付けず、親に1つだけ付けてバブリングで拾う手法。→ 第7章

**インデックス (index)**
配列の要素の位置を表す番号。**0から始まる**。→ 第3章

**エスケープ (escape)**
特別な意味を持つ文字を、無害な表記に置き換えること。`<` → `&lt;` など。→ 第6章・第12章

**オブジェクト (object)**
`{ key: value }` の形でデータをまとめたもの。名前で値を取り出す。→ 第3章

### か行

**キー (key)**
オブジェクトの中で値に付けられた名前。`entries["2026-09-16"]` の `"2026-09-16"` の部分。

**コールバック関数 (callback)**
別の関数に引数として渡される関数。`map((n) => n * 2)` の `(n) => n * 2` の部分。→ 第4章・第10章

**コンソール (Console)**
開発者ツールの中で、JavaScript を実行したりログを見たりする場所。→ 第0章

### さ行

**三項演算子 (conditional operator)**
`条件 ? A : B`。値を返す `if`。→ 第5章

**スコープ (scope)**
変数が見える範囲。`{ }` の中だけで見えるのがブロックスコープ。→ 第4章

**スプレッド構文 (spread syntax)**
`{ ...obj }` や `[...arr]`。中身を展開する記法。コピーや結合に使う。→ 第3章

**正規表現 (regular expression)**
文字列のパターンを表す記法。`/^\d{4}-\d{2}-\d{2}$/` など。→ 第8章

**宣言 (declaration)**
`const x = 1;` のように変数や関数を作ること。

**早期リターン (early return)**
条件に合わない場合を先に `return` で弾き、ネストを浅く保つ書き方。→ 第4章

### た行

**代入 (assignment)**
`x = 1` のように値を入れること。`===` (比較) と混同しないこと。

**定数 (constant)**
`const` で作った、再代入できない変数。

**テンプレートリテラル (template literal)**
`` `${変数}を含む文字列` ``。バッククォートで囲む。→ 第2章

**トランザクション**
一連の処理をまとめて「全部成功」か「全部やり直し」にする考え方。→ 第9章

### な行

**名前空間 (namespace)**
名前の衝突を避けるために、まとめ役のオブジェクトを1つ作ること。→ 第12章

### は行

**バブリング (bubbling)**
イベントが内側の要素から外側へ伝わっていく仕組み。→ 第7章

**バリデーション (validation)**
入力が正しい形かを検証すること。→ 第8章

**引数 (argument / parameter)**
関数に渡す値。→ 第4章

**プリミティブ (primitive)**
数値・文字列・真偽値・`null`・`undefined` など、オブジェクトでない値。代入すると値がコピーされる。→ 第3章

**プロパティ (property)**
オブジェクトが持つ値。`entry.condition` の `condition` の部分。

**防御的プログラミング (defensive programming)**
想定外の入力や失敗に備えてコードを書くこと。→ 第11章

### ま行

**マジックナンバー**
コード中に直接書かれた、意味の分からない数値。名前付き定数にすべき。→ 第2章

**メソッド (method)**
オブジェクトに属する関数。`array.map(...)` の `map` など。

**メソッドチェーン**
`.a().b().c()` と繋げて書くこと。→ 第10章

**戻り値 (return value)**
関数が `return` で返す値。→ 第4章

### や・ら・わ行

**要素 (element)**
HTML のタグ1つ分。`<div>` や `<button>` など。

**ライブラリ (library)**
他人が書いた再利用可能なコードの集まり。**このアプリは使っていない**。

**リスナー (listener)**
イベントが起きたときに実行される関数。→ 第7章

### アルファベット

**API**
プログラムから使える機能の窓口。`localStorage` や `fetch` など。

**DOM (Document Object Model)**
HTML をオブジェクトの木構造にしたもの。JavaScript が触るのはこれ。→ 第6章

**falsy / truthy**
`if` で `false` 扱いになる値 / `true` 扱いになる値。→ 第5章

**IIFE (Immediately Invoked Function Expression)**
`(function(){...})()`。定義してすぐ実行する関数。変数を外に漏らさない。→ 第12章

**JSON (JavaScript Object Notation)**
データを文字列で表す形式。`JSON.stringify` / `JSON.parse` で変換する。→ 第9章

**localStorage**
ブラウザにデータを永続保存する仕組み。文字列のみ・約5MB。→ 第9章

**SVG (Scalable Vector Graphics)**
図形を XML で表す画像形式。拡大しても劣化しない。→ 第12章

**XSS (Cross-Site Scripting)**
ユーザーの入力に混ぜられたスクリプトが実行されてしまう脆弱性。
`textContent` を使えば防げる。→ 第6章

## チートシート

### 変数

```js
const x = 1;            // 再代入しない (基本はこれ)
let y = 1;              // 再代入する
// var は使わない
```

### 型の変換と判定

```js
Number("7")             // 7       (Number("") は 0 なので注意)
String(7)               // "7"
Boolean(値)             // true / false
typeof 値               // "number" / "string" / "object" / ...
Array.isArray(値)       // 配列か
Number.isInteger(値)    // 整数か (NaN も false)
Number.isFinite(値)     // 有限の数値か (Infinity も false)
```

### 比較

```js
a === b     // 等しい (必ずこちら)
a !== b     // 等しくない
a == null   // null または undefined (これだけは == を使ってよい)
```

### 文字列

```js
`${a}と${b}`              // テンプレートリテラル
s.trim()                  // 前後の空白を除く
s.slice(0, 10)            // 0〜9文字目
s.split("-")              // "a-b" → ["a", "b"]
s.startsWith("2026")      // 先頭が一致するか
s.includes("頭痛")         // 含むか
s.toLowerCase()           // 小文字に
s.replace(/&/g, "&amp;")  // 置換 (g は全部置換)
s.padStart(2, "0")        // "9" → "09"
```

### 配列

```js
arr.map(fn)              // 変換             → 新しい配列
arr.filter(fn)           // 絞り込み         → 新しい配列
arr.find(fn)             // 最初の1つ        → 要素 / undefined
arr.some(fn)             // 1つでもあるか    → true / false
arr.every(fn)            // 全部そうか       → true / false
arr.includes(v)          // 含むか           → true / false
arr.slice(0, 3)          // 切り出し         → 新しい配列
arr.join(",")            // 連結             → 文字列
arr.reduce(fn, init)     // 集計             → 1つの値

arr.sort(fn)             // 並べ替え  ★元を変える
arr.reverse()            // 逆順      ★元を変える
arr.push(v)              // 末尾に追加 ★元を変える
```

### オブジェクト

```js
obj.key                  // 読む (キーが固定)
obj[変数]                 // 読む (キーが変数)
obj.key = v              // 書く
delete obj.key           // 消す
Object.keys(obj)         // キーの配列
Object.values(obj)       // 値の配列
{ ...obj }               // 浅いコピー
{ ...a, ...b }           // 結合 (b が優先)
const { a, b } = obj     // 分割代入
```

### 制御構文

```js
if (条件) { } else if (条件) { } else { }
条件 ? A : B

for (const v of 配列) { }
for (let i = 0; i < n; i++) { }
while (条件) { }
continue     // この回を飛ばす
break        // ループを抜ける
```

### 関数

```js
function name(a, b) { return a + b; }
const name = (a, b) => a + b;
const name = (a) => { ... return x; };
```

### DOM

```js
document.getElementById("id")
document.querySelector(".class")
document.querySelectorAll("tag")
el.closest(".parent")

el.textContent = "文字"          // ★ユーザー入力はこれ
el.value                          // input/select/textarea の値 (必ず文字列)
el.hidden = true
el.dataset.foo                    // data-foo 属性
el.setAttribute("aria-label", "説明")

el.classList.add("c")
el.classList.remove("c")
el.classList.toggle("c", 真偽値)  // 第2引数が便利

document.createElement("div")
document.createElementNS("http://www.w3.org/2000/svg", "line")   // ★SVG はこちら
parent.appendChild(child)
parent.append(a, b)
parent.replaceChildren()          // 中身を全消し
el.remove()
```

### イベント

```js
el.addEventListener("click", 関数)       // ★() を付けない
el.addEventListener("submit", (ev) => {
  ev.preventDefault();
});
ev.target                                 // クリックされた要素
ev.target.closest("button")               // イベント委譲の定石
```

### 保存

```js
localStorage.setItem("key", "文字列")
localStorage.getItem("key")               // 無ければ null
localStorage.removeItem("key")
JSON.stringify(obj)                       // オブジェクト → 文字列
JSON.stringify(obj, null, 2)              // 整形して出力
JSON.parse(str)                           // 文字列 → オブジェクト
```

### 日付

```js
new Date()                       // 現在時刻
d.getFullYear()                  // 2026
d.getMonth()                     // ★0〜11 (1月が 0)
d.getDate()                      // 1〜31
d.getDay()                       // 0〜6 (日曜が 0)
d.toISOString()                  // "2026-09-16T10:30:00.000Z"
d.setDate(d.getDate() + 1)       // 日付をずらす (月またぎも自動)
```

### エラー処理

```js
try {
  // 失敗するかもしれない処理
} catch (e) {
  console.warn("説明", e);
}
```

### よく使うイディオム

```js
const v = x || "既定値";                 // x が falsy なら既定値
if (!el) return;                          // 存在しなければ何もしない
arr.filter(Boolean);                      // falsy な要素を除く
Math.round(x * 10) / 10;                  // 小数第1位に丸める
Math.min(Math.max(x, 0), 12);             // 0〜12 に収める (clamp)
[...new Set(arr)];                        // 重複を除いた配列
JSON.stringify(a) !== JSON.stringify(b);  // オブジェクトの中身を比較
```

## よくあるエラーと対処

| エラー | 原因 | 対処 |
| --- | --- | --- |
| `Cannot read properties of null` | `getElementById` が見つけられなかった | id のスペル、`<script>` の位置を確認 |
| `xxx is not defined` | 変数名のタイプミス、スコープ外 | 綴りとスコープを確認 |
| `xxx is not a function` | 関数名のミス、`()` の付け間違い | 綴りを確認。`typeof xxx` で調べる |
| `Unexpected token` | カッコ・引用符の閉じ忘れ | エディタの色分けを見る |
| `Assignment to constant variable` | `const` に再代入した | `let` にするか、代入をやめる |
| `Unexpected end of JSON input` | `JSON.parse` に壊れた文字列 | 中身を `console.log` で確認 |
| 計算結果が `NaN` | 文字列を計算した、0で割った | `Number()` の変換と、0件の場合を確認 |
| `"5" + 3` が `"53"` | 文字列の結合になった | `Number()` で変換 |
| 何も起きない | `addEventListener` に `関数()` を渡した | `()` を外す |
| フォーム送信でページが再読み込み | `preventDefault()` を忘れた | `ev.preventDefault();` を追加 |
