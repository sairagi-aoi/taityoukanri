### 問4. 平均スコアを表示する (第4章・第10章)

ヘッダーの「連続 3 日」の隣に、**今月の体調の平均スコア** を表示してください。

例: `今月の体調平均 3.8`

**ヒント**:
- `index.html` に `<span id="avg-info" class="streak-info"></span>` を追加
- 今月の日付は `d.startsWith(currentYearMonth())` で絞れる
- 平均は `reduce` で合計を出して件数で割る。または `for...of` でも可
- 小数第1位までにするには `Math.round(avg * 10) / 10` または `avg.toFixed(1)`
- `updateHeaderStatus()` の中に処理を追加すると、更新のタイミングが自動で合う
- **0件のときの扱い** を忘れずに (0で割ると `NaN` になります)

### 問7. CSV でも書き出せるようにする (第10章・第12章)

「Excelで書き出し」の隣に「CSVで書き出し」ボタンを追加してください。

**ヒント**:
- `buildExportRows()` がそのまま使えます
- CSV は各行をカンマで繋ぎ、行を改行で繋いだテキストです
- **値にカンマ・改行・ダブルクォートが含まれる場合の処理が必要です**
  (メモに「今日は、よく眠れた」と書かれたら？)
  ルール: 値を `"` で囲み、値の中の `"` は `""` に置き換える
- 文字コードは UTF-8。Excel で開いたときに文字化けするなら **BOM** を付けます
  ```js
  const BOM = String.fromCharCode(0xFEFF);   // U+FEFF
  new Blob([BOM + csvText], { type: "text/csv;charset=utf-8" })
  ```
- ダウンロードの手順は `exportExcel` と同じです

### 問8. タグ機能を追加する (第3章・第6章・第9章)

各記録に **タグ** (「頭痛」「残業」「運動した」など複数) を付けられるようにしてください。

**考えるべきこと**:

- 入力 UI をどうするか (カンマ区切りのテキスト入力が一番簡単です)
- `normalizeEntry` での検証をどう追加するか (配列か？ 各要素は文字列か？ 個数の上限は？)

- 一覧での表示をどうするか
- Excel 書き出しに含めるか

**ヒント**: 既存データとの互換性を保つには、`tags` が無い場合に `[]` を補う処理が要ります。
```js
const tags = Array.isArray(raw.tags) ? raw.tags.filter(t => typeof t === "string") : [];
```

### 問9. データのインポート機能 (第9章・第11章・第12章)

現在このアプリは書き出しはできますが、**読み込みができません**。
端末を変えるとデータを移せないという実用上の問題があります。

「JSONで書き出し」と「JSONから読み込み」の2つを実装してください。

**ヒント**:
- 書き出し: `JSON.stringify(entries, null, 2)` を Blob にして `.json` でダウンロード
- 読み込み: `<input type="file" accept=".json">` を使う
  ```js
  fileInput.addEventListener("change", async (ev) => {
    const file = ev.target.files[0];
    if (!file) return;
    const text = await file.text();
    // ...
  });
  ```
- **読み込んだデータは絶対に信用しないこと** (第11章)。`normalizeStore` を必ず通す
- 既存データとどうするか決める: 全置換か、マージ (同じ日付は上書き) か
- **取り返しがつかない操作なので `confirm` を出す**
- 何件読み込めたか、何件が不正で捨てられたかを `flash` で伝える

### 問10. コードを分割する (第4章・第12章)

`app.js` は約830行あります。これを役割ごとのファイルに分割してください。

**分割の案**:

| ファイル | 中身 |
| --- | --- |
| `constants.js` | `OPTIONS`, `SCORE_FIELDS`, `FIELD_LABELS`, `STORAGE_KEY` など |
| `utils.js` | `todayString`, `addDays`, `formatDateJa`, `formatHours`, `labelOf` |
| `storage.js` | `loadEntriesRaw`, `normalizeEntry`, `normalizeStore`, `saveEntries` |
| `render.js` | `renderList`, `renderTrendsChart`, `updateHeaderStatus` |
| `app.js` | フォーム処理とイベント登録 |

**考えるべきこと**:
- `<script type="module">` と `import` / `export` を使う方法
  → きれいだが **ローカルファイル (`file://`) では動かない**。サーバーが必要
- IIFE のまま、グローバルに1つだけ名前空間オブジェクトを作る方法
  → `file://` でも動く。`window.TaichouApp = { ... }` のような形
- `entries` のような共有される状態を、どのファイルが持つべきか

**このアプリの価値は「ダブルクリックで動く」ことです。**
それを壊さない分割方法を考えてください。分割しないという結論もありえます。
**その場合は、なぜ分割しないほうが良いのか理由を書いてください。**

## おまけ課題

余力のある人向けです。

### A. 週次サマリー
直近7日間の各項目の平均を表にして表示する。

### B. キーボードショートカット
`Ctrl/Cmd + S` で保存する。`keydown` イベントと `ev.preventDefault()` を使います。

### C. 印刷用スタイル
`@media print { }` を `style.css` に追加し、印刷時にフォームやボタンを隠して
一覧だけがきれいに印刷されるようにする。JavaScript は一切不要です。

### D. データの暗号化
`localStorage` の中身は誰でも読めます。パスワードで暗号化してから保存する。
`crypto.subtle` API を使います。**かなり難しく、鍵の管理という新しい問題も生まれます。**
「暗号は自分で作らない」という鉄則も含めて調べてみてください。

### E. PWA 化
`manifest.json` と Service Worker を追加して、スマホのホーム画面に追加できるようにする。
オフラインでも動くアプリになります。
