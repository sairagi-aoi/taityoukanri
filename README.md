# 体調記録

HTML / CSS / JavaScript だけで動く、その日の体調を記録する小さなWebアプリです。外部ライブラリは使っていません。

## 使い方

`index.html` をブラウザで開くだけで動きます (サーバー不要)。

1. 日付を確認 (初期値は今日)
2. 体調・メンタルの安定度・食欲・意欲・睡眠の質をプルダウンから選択
3. 睡眠時間を数値で入力 (0.5 時間刻み)
4. 「保存する」を押す

- 1日1件。同じ日付で保存すると上書きされます (ボタンが「上書き保存する」に変わります)
- 一覧の「編集」で過去の記録をフォームに読み込めます
- 「Excelで書き出し」で `.xlsx` ファイルをダウンロードできます
  (ラベル列とスコア列 1〜5 の両方が入るので、Excel でそのままグラフ化できます)

## データの保存先

ブラウザの `localStorage` に保存されます。別のブラウザ・別の端末には共有されないので、
バックアップしたい場合は Excel で書き出してください。

## ファイル構成

| ファイル     | 内容                                            |
| ------------ | ----------------------------------------------- |
| `index.html` | 画面                                            |
| `style.css`  | スタイル (ダークモード対応)                     |
| `app.js`     | 入力・保存・一覧表示                            |
| `xlsx.js`    | 外部ライブラリなしで `.xlsx` を生成する自作処理 |
